# removeObserver(_:forPageSpread:)

Stops reporting a spread’s download state to an observer.

```
func removeObserver(_ observer: PSEPageSpreadObserver, forPageSpread pageSpread: PSEPageSpread)
```

## Parameters

`observer`

The observer to stop notifying.

`pageSpread`

The spread it was observing.
