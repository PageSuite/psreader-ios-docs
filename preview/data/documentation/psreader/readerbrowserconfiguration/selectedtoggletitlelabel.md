# selectedToggleTitleLabel

Appearance configuration for content toggle button titles when selected.

```
var selectedToggleTitleLabel: LabelConfiguration
```

## Discussion

Controls the typography and color of toggle button text when the button is selected.
Selected titles typically use a bold style or distinct color to highlight
the user’s current selection.
