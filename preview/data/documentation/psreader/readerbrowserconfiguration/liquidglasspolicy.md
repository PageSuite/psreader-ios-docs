# liquidGlassPolicy

Liquid Glass policy for the reader content browser.

```
var liquidGlassPolicy: LiquidGlassPolicy
```

## Discussion

Controls adoption of the iOS 26+ Liquid Glass effect within the browser
interface. Defaults to the value from `GlobalConfiguration`and can be
overridden here for finer control.
