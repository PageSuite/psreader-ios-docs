# toggleBackgroundColor

Background color for content toggle buttons in their unselected state.

```
var toggleBackgroundColor: UIColor
```

## Discussion

Content toggles allow users to switch between different views (e.g., pages vs articles).
This color is applied to toggle buttons that are not currently selected.
