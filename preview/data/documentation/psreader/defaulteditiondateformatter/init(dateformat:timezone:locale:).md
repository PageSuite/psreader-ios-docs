# init(dateFormat:timeZone:locale:)

Initializes a new formatter with the given date format and time zone.

```
init(dateFormat: String = "MMMM d, yyyy", timeZone: TimeZone = .current, locale: Locale = .current)
```

## Parameters

`dateFormat`

The date format string (default: “MMMM d, yyyy”).

`timeZone`

The time zone for date formatting (defaults to current time zone).

`locale`

The locale for date formatting (defaults to current locale).
