# legacyImageResource(for:)

Returns the legacy replica reader’s built-in image for the asset, from
[`defaultImage()`](/documentation/PSReader/LegacyImageResourceName/defaultImage()).

```
func legacyImageResource(for name: LegacyImageResourceName) -> UIImage?
```

## Parameters

`name`

The identifier for the requested legacy image
resource.

## Return Value

The built-in image.
