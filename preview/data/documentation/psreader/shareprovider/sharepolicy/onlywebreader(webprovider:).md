# ShareProvider.SharePolicy.onlyWebReader(webProvider:)

Shares exclusively to the web reader.

```
case onlyWebReader(webProvider: WebReaderShareProvider)
```

## Parameters

`webProvider`

A configured `WebReaderShareProvider` responsible
for generating share links to your web reader.
