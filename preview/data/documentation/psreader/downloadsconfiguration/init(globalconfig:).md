# init(globalConfig:)

Initializes a new downloads configuration with defaults provided by the global SDK configuration object.

```
init(globalConfig: GlobalConfiguration)
```

## Parameters

`globalConfig`

The global SDK configuration supplying default fonts, colors, and branding.

## Discussion

Default settings ensure consistent branding, fonts, and visual styles across the SDK components.
