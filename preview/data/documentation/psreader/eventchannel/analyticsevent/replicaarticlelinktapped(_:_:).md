# EventChannel.AnalyticsEvent.replicaArticleLinkTapped(_:_:)

Fires when a URL is tapped in a replica article view.

```
case replicaArticleLinkTapped(URL, ReplicaArticleEventContext)
```

## Parameters

`url`

The `URL` of the link that was tapped.

The `ReplicaArticleEventContext` for this event.
