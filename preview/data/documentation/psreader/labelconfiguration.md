# LabelConfiguration

Configuration object that specifies the appearance of `UILabels` used
throughout the prebuilt UI.

```
struct LabelConfiguration
```

## Overview

For the prebuilt UI’s other appearance settings, see [Theming](/documentation/PSReader/Theming).

## Topics

### Styling Text

[`font`](/documentation/PSReader/LabelConfiguration/font)

The base font of the label.

[`pointSize`](/documentation/PSReader/LabelConfiguration/pointSize)

The desired point size of the font.

[`color`](/documentation/PSReader/LabelConfiguration/color)

The color of the label text.
