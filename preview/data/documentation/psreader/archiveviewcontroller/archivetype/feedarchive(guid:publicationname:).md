# ArchiveViewController.ArchiveType.feedArchive(guid:publicationName:)

An archive screen for editions on PageSuite’s current system,
classic PDF or responsive.

```
case feedArchive(guid: String, publicationName: String)
```

## Parameters

`guid`

The application GUID of the publication to load.

`publicationName`

The name of the publication to display.
