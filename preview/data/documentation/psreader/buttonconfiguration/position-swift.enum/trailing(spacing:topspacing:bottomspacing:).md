# ButtonConfiguration.Position.trailing(spacing:topSpacing:bottomSpacing:)

Positions the button on the trailing edge (right edge in left-to-right layouts).

```
case trailing(spacing: CGFloat = 16, topSpacing: CGFloat = 0, bottomSpacing: CGFloat = 0)
```

## Parameters

`spacing`

Horizontal spacing from the trailing edge.

`topSpacing`

Vertical spacing from the top edge.

`bottomSpacing`

Vertical spacing from the bottom edge.
