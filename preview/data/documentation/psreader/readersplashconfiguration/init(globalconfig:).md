# init(globalConfig:)

Initializes a new splash screen configuration using defaults from the provided global SDK configuration.

```
init(globalConfig: GlobalConfiguration)
```

## Parameters

`globalConfig`

The global configuration object containing default fonts, colors, and settings.

## Discussion

Defaults ensure visual consistency and adherence to app-wide branding.
