# BookmarksConfiguration.BookmarkType

An option set representing the types of bookmarks supported by the bookmarks view.

```
struct BookmarkType
```

## Topics

### Bookmark Types

[`feedArticle`](/documentation/PSReader/BookmarksConfiguration/BookmarkType/feedArticle)

Bookmarked articles from editions on PageSuite’s current system.

[`feedPage`](/documentation/PSReader/BookmarksConfiguration/BookmarkType/feedPage)

Bookmarked pages from editions on PageSuite’s current system.

[`all`](/documentation/PSReader/BookmarksConfiguration/BookmarkType/all)

Convenience option representing all bookmark types.

### Replica Editions

[`replicaArticle`](/documentation/PSReader/BookmarksConfiguration/BookmarkType/replicaArticle)

Bookmarked articles from legacy replica editions.

[`replicaPage`](/documentation/PSReader/BookmarksConfiguration/BookmarkType/replicaPage)

Bookmarked pages from legacy replica editions.
