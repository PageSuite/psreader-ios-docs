# init(text:font:preferredWidth:foregroundColor:backgroundColor:)

Creates a new tooltip view controller.

```
@MainActor init(text: String, font: UIFont, preferredWidth: CGFloat = 340, foregroundColor: UIColor? = nil, backgroundColor: UIColor? = nil)
```

## Parameters

`text`

The tooltip message to display.

`font`

The label font.

`preferredWidth`

The preferred popover width. Default `340`.

`foregroundColor`

The text and close-button tint color.

`backgroundColor`

The tooltip background color.
