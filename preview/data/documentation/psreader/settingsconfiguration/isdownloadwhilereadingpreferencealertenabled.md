# isDownloadWhileReadingPreferenceAlertEnabled

Indicates whether the SDK should prompt users about their download while
reading preference the first time they open the reader.

```
var isDownloadWhileReadingPreferenceAlertEnabled: Bool
```

## Discussion

If enabled (`true`), the SDK will prompt users to choose their download
behavior preference upon their first interaction with the reader.
