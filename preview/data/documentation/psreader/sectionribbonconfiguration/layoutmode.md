# SectionRibbonConfiguration.LayoutMode

Determines how the section titles are laid out horizontally within the ribbon.

```
enum LayoutMode
```

## Topics

### Layout Modes

[`SectionRibbonConfiguration.LayoutMode.fitLeft`](/documentation/PSReader/SectionRibbonConfiguration/LayoutMode/fitLeft)

Section titles align to the left with natural spacing.

[`SectionRibbonConfiguration.LayoutMode.fitCenter`](/documentation/PSReader/SectionRibbonConfiguration/LayoutMode/fitCenter)

Section titles are centered horizontally within the ribbon with natural spacing.

[`SectionRibbonConfiguration.LayoutMode.fillEqually`](/documentation/PSReader/SectionRibbonConfiguration/LayoutMode/fillEqually)

Each section title occupies equal horizontal space, distributing evenly
across the entire ribbon width.
