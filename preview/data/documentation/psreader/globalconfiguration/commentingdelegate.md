# commentingDelegate

Optional delegate for enabling commenting functionality within the reader.

```
var commentingDelegate: CommentingDelegate?
```

## Discussion

Set it to a [`DefaultCommentingProvider`](/documentation/PSReader/DefaultCommentingProvider) to show comment buttons and
counts on articles.
