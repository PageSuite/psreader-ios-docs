# init(popOverArticleMessageTemplate:popOverArticleSubjectTemplate:shareEditionPageMessageTemplate:shareEditionPageSubjectTemplate:subscribeUrl:publicationName:appStoreLink:)

Initializes a new share templater with the specified template strings and URLs.

```
init(popOverArticleMessageTemplate: String? = nil, popOverArticleSubjectTemplate: String? = nil, shareEditionPageMessageTemplate: String? = nil, shareEditionPageSubjectTemplate: String? = nil, subscribeUrl: String? = nil, publicationName: String? = nil, appStoreLink: String? = nil)
```

## Parameters

`popOverArticleMessageTemplate`

Share message template for articles.

`popOverArticleSubjectTemplate`

Share subject template for articles.

`shareEditionPageMessageTemplate`

Share message template for pages.

`shareEditionPageSubjectTemplate`

Share subject template for pages.

`subscribeUrl`

Subscription URL for inclusion in share messages.

`publicationName`

Publication name to include in share templates.

`appStoreLink`

App Store URL included in share templates.
