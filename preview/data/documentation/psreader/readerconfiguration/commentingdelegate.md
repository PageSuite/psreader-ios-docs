# commentingDelegate

Optional delegate enabling commenting functionality within the reader.

```
var commentingDelegate: CommentingDelegate?
```

## Discussion

Starts as the global configuration’s [`commentingDelegate`](/documentation/PSReader/GlobalConfiguration/commentingDelegate);
set it to change commenting for this reader only.
