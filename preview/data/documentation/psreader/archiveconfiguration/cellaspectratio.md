# cellAspectRatio

Aspect ratio for thumbnails representing editions in the archive view.

```
var cellAspectRatio: CGFloat
```

## Discussion

Defaults to `0.9` (typically portrait-oriented).
Adjust this to match your publications typical thumbnail.
