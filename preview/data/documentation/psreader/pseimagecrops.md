# PSEImageCrops

The set of crop variants available for an image.

```
@objc class PSEImageCrops
```

## Topics

### Crops by Aspect Ratio

[`crop32`](/documentation/PSReader/PSEImageCrops/crop32)

The crop at a 3:2 aspect ratio, or `nil` when the backend supplies
none.

[`crop23`](/documentation/PSReader/PSEImageCrops/crop23)

The crop at a 2:3 aspect ratio, or `nil` when the backend supplies
none.

[`crop11`](/documentation/PSReader/PSEImageCrops/crop11)

The square (1:1) crop, or `nil` when the backend supplies none.
