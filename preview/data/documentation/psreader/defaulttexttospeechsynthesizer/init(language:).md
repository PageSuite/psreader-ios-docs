# init(language:)

Creates a new text-to-speech synthesizer for the specified language.

```
init(language: String = "en")
```

## Parameters

`language`

The language code for synthesis. Defaults to “en” (English).
Use standard language codes like “en”, “es”, “fr”, etc.
