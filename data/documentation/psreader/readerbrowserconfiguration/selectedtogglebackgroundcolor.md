# selectedToggleBackgroundColor

Background color for the selected content toggle button.

```
var selectedToggleBackgroundColor: UIColor
```

## Discussion

This color highlights the currently active toggle button, providing visual feedback
about which content view is currently displayed. Defaults to brand color.
