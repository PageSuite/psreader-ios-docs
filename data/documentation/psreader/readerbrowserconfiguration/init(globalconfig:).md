# init(globalConfig:)

Initializes a new content browser configuration using the provided global SDK configuration.

```
init(globalConfig: GlobalConfiguration)
```

## Parameters

`globalConfig`

The global configuration providing defaults for colors, fonts, and theming.

## Discussion

Default colors, fonts, and visual styles are inherited from the global configuration
to ensure visual consistency and alignment with app-wide branding.
