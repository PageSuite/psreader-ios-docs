# toggleTitleLabel

Appearance configuration for content toggle button titles in their default (unselected) state.

```
var toggleTitleLabel: LabelConfiguration
```

## Discussion

Controls the typography and color of toggle button text when the button is not selected.
Use this to ensure toggle buttons align with your app’s overall text styling.
