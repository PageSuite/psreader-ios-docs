# LocalizedStringKey.failedToLoadPageErrorMessage

Error message displayed when a streamed edition fails to load a page.
Default value: `"Failed to load page.\nPlease check your connection and retry."`.

```
case failedToLoadPageErrorMessage
```

## Discussion

The default value is two lines.
