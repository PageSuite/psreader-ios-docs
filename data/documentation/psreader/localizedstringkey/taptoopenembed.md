# LocalizedStringKey.tapToOpenEmbed

Title text for the HTML button that replaces embedded content in multi-column templates.
Appears as a call-to-action (CTA) in place of iframes, embeds, or social media blockquotes.
Tapping the button opens the original embed in an in-app overlay or WebView.
Default value: `"Tap to open embed"`.
