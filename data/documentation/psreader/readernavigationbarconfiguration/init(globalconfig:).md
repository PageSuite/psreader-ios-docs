# init(globalConfig:)

Initializes a new navigation bar configuration with defaults derived from
the provided global SDK configuration.

```
init(globalConfig: GlobalConfiguration)
```

## Parameters

`globalConfig`

The global configuration object supplying default fonts, colors, and branding.
