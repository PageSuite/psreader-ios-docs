# init(activityItems:applicationActivities:subject:)

Initializes a new share context with provided items and optional subject and activities.

```
init(activityItems: [Any], applicationActivities: [UIActivity]? = nil, subject: String? = nil)
```

## Parameters

`activityItems`

The primary items to be shared.

`applicationActivities`

Custom share actions or activities (optional).

`subject`

Optional subject line associated with the shared content.
