# bookmarkDate

The edition’s date as display text, copied from the edition when the
page was bookmarked.

```
@objc var bookmarkDate: String?
```

## Discussion

To format the date yourself, use [`editionDate`](/documentation/PSReader/PSEBookmarkPage/editionDate).
