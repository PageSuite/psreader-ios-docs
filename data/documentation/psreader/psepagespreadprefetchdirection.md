# PSEPageSpreadPrefetchDirection

The reading direction driving a prefetch request.

```
enum PSEPageSpreadPrefetchDirection
```

## Topics

### Directions

[`PSEPageSpreadPrefetchDirection.forward`](/documentation/PSReader/PSEPageSpreadPrefetchDirection/forward)

The user is paging toward the back of the edition.

[`PSEPageSpreadPrefetchDirection.backward`](/documentation/PSReader/PSEPageSpreadPrefetchDirection/backward)

The user is paging toward the front of the edition.

[`PSEPageSpreadPrefetchDirection.neutral`](/documentation/PSReader/PSEPageSpreadPrefetchDirection/neutral)

No established direction — for example, after a jump.
