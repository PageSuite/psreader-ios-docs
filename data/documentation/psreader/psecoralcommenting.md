# PSECoralCommenting

Coral commenting identifiers for an article.

```
@objc class PSECoralCommenting
```

## Overview

Read it from [`coralCommenting`](/documentation/PSReader/PSEArticleMetadata/coralCommenting) to open the article’s
comment stream in your own Coral integration, as [`CoralCommentingService`](/documentation/PSReader/CoralCommentingService)
does to fetch comment counts.

## Topics

### Commenting Identifiers

[`enabled`](/documentation/PSReader/PSECoralCommenting/enabled)

Whether commenting is enabled for the article.

[`assetId`](/documentation/PSReader/PSECoralCommenting/assetId)

The Coral asset ID of the article’s comment stream.

[`publicUrl`](/documentation/PSReader/PSECoralCommenting/publicUrl)

The public URL Coral associates with the article’s comment stream.
