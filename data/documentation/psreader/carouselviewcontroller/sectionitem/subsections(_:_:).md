# CarouselViewController.SectionItem.subsections(_:_:)

Multiple subsections with the given section name and [`CarouselViewController.Content`](/documentation/PSReader/CarouselViewController/Content).

```
case subsections(String, [Content])
```

## Parameters

`name`

The name of the section.

`content`

Array of [`CarouselViewController.Content`](/documentation/PSReader/CarouselViewController/Content) objects describing the subsections.
