# DefaultTextToSpeechArticleFormatter

Default implementation of text-to-speech article formatting.

```
struct DefaultTextToSpeechArticleFormatter
```

## Overview

This formatter provides a standard implementation for converting article content
into text suitable for speech synthesis. It handles common formatting tasks such as
HTML cleanup, text structure optimization, and content preparation for natural narration.

The default formatter is designed to work with most articles and provides
sensible defaults for text-to-speech conversion.
