# border

Whether the hotspot has a border.

```
@objc var border: Bool
```

## Discussion

When it’s `true`, [`PSEMediaOverlay`](/documentation/PSReader/PSEMediaOverlay) draws a 1-point border in
[`borderColor`](/documentation/PSReader/PSEMediaObject/borderColor) at [`borderAlpha`](/documentation/PSReader/PSEMediaObject/borderAlpha).
