# aspectRatio

Aspect ratio applied to bookmark thumbnails displayed within the view.

```
var aspectRatio: CGFloat
```

## Discussion

Defaults to `0.65` for a portrait-oriented presentation.
Adjust this to match your publications typical thumbnail.
