# LegacyReaderConfiguration.NavigationBarItem

An option set representing available navigation bar items within the legacy reader.

```
struct NavigationBarItem
```

## Topics

### Buttons

[`share`](/documentation/PSReader/LegacyReaderConfiguration/NavigationBarItem/share)

Enables content sharing button.

[`bookmark`](/documentation/PSReader/LegacyReaderConfiguration/NavigationBarItem/bookmark)

Enables bookmarking functionality.

[`print`](/documentation/PSReader/LegacyReaderConfiguration/NavigationBarItem/print)

Enables the print button.

[`textSize`](/documentation/PSReader/LegacyReaderConfiguration/NavigationBarItem/textSize)

Enables text size adjustment controls.

[`doublePageLandscape`](/documentation/PSReader/LegacyReaderConfiguration/NavigationBarItem/doublePageLandscape)

Enables double-page mode when in landscape orientation.
