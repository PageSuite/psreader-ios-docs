# init(globalConfig:)

Initializes a new legacy reader configuration using defaults inherited from the global SDK configuration.

```
init(globalConfig: GlobalConfiguration)
```

## Parameters

`globalConfig`

The global configuration providing defaults for visual consistency.

## Discussion

By default, navigation bars have shadows enabled, and common navigation items
(double-page mode, bookmarks, and sharing) are activated.
