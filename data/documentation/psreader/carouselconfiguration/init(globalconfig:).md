# init(globalConfig:)

Initializes a new carousel configuration using the provided global configuration.

```
init(globalConfig: GlobalConfiguration)
```

## Parameters

`globalConfig`

The global SDK configuration used to set defaults for colors,
fonts, paywall interactions, and other visual aspects.

## Discussion

Default appearance and behaviors are derived from the global SDK configuration,
ensuring consistency across the app.
