# PSPDFLayoutMode

How the reader fits PDF pages inside the viewport.

```
enum PSPDFLayoutMode
```

## Overview

Set through [`pdfLayoutMode`](/documentation/PSReader/PSEditionReaderViewController/pdfLayoutMode).

## Topics

### Modes

[`PSPDFLayoutMode.fitToWidth`](/documentation/PSReader/PSPDFLayoutMode/fitToWidth)

The page fills the viewport width; the user scrolls vertically to
read down the page.

[`PSPDFLayoutMode.fitToHeight`](/documentation/PSReader/PSPDFLayoutMode/fitToHeight)

The whole page fits on screen.
