# isSettingsMenuItemEnabled

Whether the reader’s settings menu offers a row that plays the
walkthrough again.

```
var isSettingsMenuItemEnabled: Bool
```

## Discussion

Defaults to `true`. The row’s title is
[`LocalizedStringKey.readerOnboardingSettingsMenuItem`](/documentation/PSReader/LocalizedStringKey/readerOnboardingSettingsMenuItem).
