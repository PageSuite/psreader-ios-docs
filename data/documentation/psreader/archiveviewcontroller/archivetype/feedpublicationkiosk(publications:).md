# ArchiveViewController.ArchiveType.feedPublicationKiosk(publications:)

A grid of publications on PageSuite’s current system, each linking
to a publication landing page.

```
case feedPublicationKiosk(publications: [KioskFeedPublication])
```

## Parameters

`publications`

An array of publication entries with optional per-publication archive overrides.
