# imageResource(for:)

Returns the SDK’s built-in image for the asset, from
[`defaultImage()`](/documentation/PSReader/ImageResourceName/defaultImage()).

```
func imageResource(for name: ImageResourceName) -> UIImage?
```

## Parameters

`name`

The identifier for the requested image resource.

## Return Value

The built-in image.
