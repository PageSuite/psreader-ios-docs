# init(pageNumber:rect:)

Creates a hotspot.

```
init(pageNumber: Int, rect: CGRect)
```

## Parameters

`pageNumber`

The number of the PDF page the region is on, counting
from 1.

`rect`

The region, in percent of the page’s width and height, with
the origin at the top left.
