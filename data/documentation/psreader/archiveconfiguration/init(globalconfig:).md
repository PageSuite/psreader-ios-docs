# init(globalConfig:)

Initializes an `ArchiveConfiguration` using the provided global configuration.

```
init(globalConfig: GlobalConfiguration)
```

## Parameters

`globalConfig`

The global SDK configuration providing defaults for theming, assets, and delegates.

## Discussion

Defaults are inherited from the global configuration’s theming and branding.
