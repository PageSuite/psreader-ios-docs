# EventChannel.AnalyticsEvent.feedEditionContentBrowserSectionTapped(_:)

Fires when the user taps a section in the reader’s contents browser.

```
case feedEditionContentBrowserSectionTapped(FeedEditionEventContext)
```

## Parameters

`context`

The `FeedEditionEventContext` for this event.
Its page spread is the spread the reader was
showing when the browser opened.
