# EventChannel.AnalyticsEvent.replicaPageLinkTapped(_:_:)

Fires when a URL is tapped in a replica page view.

```
case replicaPageLinkTapped(URL, ReplicaEventContext)
```

## Parameters

`url`

The `URL` of the link that was tapped.

The `ReplicaEventContext` for this event.
