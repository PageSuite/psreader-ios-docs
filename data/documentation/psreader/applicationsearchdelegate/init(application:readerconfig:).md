# init(application:readerConfig:)

Creates a search delegate from an existing application.

```
init(application: PSAppConfig, readerConfig: ReaderConfiguration)
```

## Parameters

`application`

The application containing archive and publication data.

`readerConfig`

The base reader configuration to tweak per-publication.
