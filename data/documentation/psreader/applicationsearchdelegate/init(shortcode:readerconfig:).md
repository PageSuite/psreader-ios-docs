# init(shortcode:readerConfig:)

Creates a search delegate that fetches the application from a shortcode on first use.

```
init(shortcode: String, readerConfig: ReaderConfiguration)
```

## Parameters

`shortcode`

The shortcode to fetch the application configuration from.

`readerConfig`

The base reader configuration to tweak per-publication.
