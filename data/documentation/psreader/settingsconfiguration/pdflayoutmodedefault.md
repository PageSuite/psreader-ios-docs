# pdfLayoutModeDefault

The default layout mode used when displaying PDF editions.

```
var pdfLayoutModeDefault: PSPDFLayoutMode
```

## Discussion

Determines how PDFs are scaled within the reader by default, such as `.fitToWidth` or `.fitToHeight`.
