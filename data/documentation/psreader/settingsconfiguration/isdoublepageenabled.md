# isDoublePageEnabled

Indicates whether the double-page viewing mode is enabled, allowing two
PDF pages to be displayed side-by-side.

```
var isDoublePageEnabled: Bool
```

## Discussion

Particularly useful for replicating the layout of traditional newspaper spreads.
