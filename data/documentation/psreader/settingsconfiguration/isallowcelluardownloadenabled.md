# isAllowCelluarDownloadEnabled

Determines whether the allow cellular download option appears in the settings menu.

```
var isAllowCelluarDownloadEnabled: Bool
```

## Discussion

When set to `false`, this preference is hidden from users. When set to `true`,
users can toggle whether downloads are allowed over cellular connections.
