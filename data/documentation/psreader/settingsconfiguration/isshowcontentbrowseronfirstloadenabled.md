# isShowContentBrowserOnFirstLoadEnabled

Determines whether the show content browser on first load option appears in the settings menu.

```
var isShowContentBrowserOnFirstLoadEnabled: Bool
```

## Discussion

When set to `false`, this preference is hidden from users. When set to `true`,
users can toggle whether the content browser shows automatically on first load.
