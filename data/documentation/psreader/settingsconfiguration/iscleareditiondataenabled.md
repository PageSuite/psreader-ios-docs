# isClearEditionDataEnabled

Determines whether the clear edition data option appears in the data settings menu.

```
var isClearEditionDataEnabled: Bool
```

## Discussion

When set to `false`, this option is hidden from users. When set to `true`,
users can access the clear edition data functionality.
