# isAutoDeleteEditionsEnabled

Determines whether the auto delete editions option appears in the data settings menu.

```
var isAutoDeleteEditionsEnabled: Bool
```

## Discussion

When set to `false`, this option is hidden from users. When set to `true`,
users can configure automatic deletion of old editions.
