# liquidGlassPolicy

Liquid Glass policy for the reader splash screen.

```
var liquidGlassPolicy: LiquidGlassPolicy
```

## Discussion

Controls adoption of the iOS 26+ Liquid Glass effect within splash views.
Defaults to the value from `GlobalConfiguration` and can be overridden here for finer control.
